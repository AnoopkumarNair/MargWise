## GitHub Actions secrets needed

Set these in the repo (Settings → Secrets and variables → Actions). None are
needed for Phase 0–1 CI; they are used from Phase 3 (pipeline, deploys).

| Secret                                                                 | Used by                                           |
| ---------------------------------------------------------------------- | ------------------------------------------------- |
| `SUPABASE_ACCESS_TOKEN`                                                | Supabase CLI in CI (migrations, function deploys) |
| `SUPABASE_STAGING_PROJECT_REF` / `SUPABASE_PROD_PROJECT_REF`           | `supabase link`                                   |
| `SUPABASE_STAGING_DB_PASSWORD` / `SUPABASE_PROD_DB_PASSWORD`           | `supabase db push`                                |
| `SUPABASE_STAGING_URL` / `SUPABASE_PROD_URL`                           | pipeline jobs                                     |
| `SUPABASE_STAGING_SERVICE_ROLE_KEY` / `SUPABASE_PROD_SERVICE_ROLE_KEY` | pipeline jobs only (never the apps)               |
| `SUPABASE_STAGING_PUBLISHABLE_KEY` / `SUPABASE_PROD_PUBLISHABLE_KEY`   | app builds (public by design)                     |
| `ANTHROPIC_API_KEY` (optional)                                         | pipeline LLM-assisted extraction (Phase 3)        |
