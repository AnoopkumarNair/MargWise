# ADR 006: IP-SF items verbatim; game delivery only; A/B against a plain arm

- **Status:** Proposed — awaiting Anu's approval
- **Date:** 2026-10-20
- **Spec:** 04 §12

## Context

The game must not distort the 60 O*NET IP-SF items (02 §4, 03 §2).

## Decision

Items transcribed verbatim from the official PDF into a fixture with a snapshot test; official 0–4 anchors on every item; fixed order; no contingent feedback. With Tier 2 consent, 50% of sessions get a plain-questionnaire arm. A simplified-wording arm only with Anu's approval, analysed as a new instrument.

## Consequences

Measurement integrity is testable. Cost: game design constrained (e.g. villager guild hidden during the market).

## Alternatives considered

Rewording items for Indian teens by default (would invalidate the instrument).
